# 项目目标

基于 Klipper 构建五轴 CNC 油画机器控制系统。

- 硬件架构：笛卡尔 XYZ + 旋转轴 AB（或 AC）用于控制画笔倾斜角度
- 应用场景：油画绘制（非 3D 打印）
- 旋转轴不耦合：使用 cartesian_abc 运动学（各轴独立笛卡尔坐标）

## 关键区别 vs 3D 打印

| 项目 | 3D 打印 | CNC 油画 |
|------|---------|---------|
| 工具 | 挤出头（点） | 画笔（有方向、有笔尖偏移） |
| RTCP 需求 | 不需要 | **必需** — 倾斜画笔时笔尖不能移位 |
| 速度模型 | 恒定挤出 | 笔触速度影响颜料厚度 |
| G-code 来源 | 切片软件 | CAM 软件 / 自定义后处理 |
| 精度要求 | 层高 ~0.1mm | 笔触 ~0.01mm |

## 关键约束

- 画笔长度（tool length）：旋转中心到笔尖的距离，需可配置
- 旋转轴在画笔上方（类似五轴 CNC 铣床的 A/B 摆头结构）
- 笛卡尔架构意味着 XYZ 和 ABC 无耦合 — RTCP 需要作为上层变换实现
